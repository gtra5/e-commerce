e-commerce
This project is a modern e-commerce web application designed for a seamless online shopping experience. It features product browsing, cart management, authentication, and integration with cloud services.

Features
Product listing and details
Shopping cart and checkout
User authentication (sign up/sign in)
Category and search functionality
Responsive design for mobile and desktop
Advertisement and promotional slides
Tools and Technologies Used
Frontend
React: For building interactive user interfaces
Vite: Fast development server and build tool for React
JavaScript (JSX): Component-based UI development
CSS: Styling and responsive layouts
Backend / Serverless Functions
Node.js: JavaScript runtime for server-side logic
Firebase Functions: Serverless backend operations
Firestore: NoSQL database for product and user data
Cloud & Integration
Firebase: Authentication, Firestore database, and hosting
Vercel: Deployment and hosting of the frontend
Development Tools
ESLint: Code linting and quality
YAML: Configuration (e.g., data connectors)
Git: Version control
Project Structure
gg/ – Main frontend React app
functions/ – Serverless backend functions
dataconnect/ – Data connector configurations and GraphQL schemas
src/dataconnect-generated/ – Auto-generated code for data connectors
This project demonstrates a full-stack approach to building scalable, cloud-native e-commerce solutions using modern web technologies.
